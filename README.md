# Sistema de Gestão de Notas e Frequência

Projeto acadêmico da disciplina de Programação de Computadores. O programa de terminal cadastra dados de um aluno e suas disciplinas, recebe três notas e o total de faltas, calcula média e frequência e informa a situação em cada disciplina.

## Funcionalidades

- Leitura e validação de notas entre 0 e 10.
- Leitura de faltas para um período configurado de 40 aulas.
- Cálculo de média e percentual de frequência.
- Classificação como aprovado, recuperação ou reprovado por nota/falta, conforme os critérios definidos no código.
- Exibição de relatório por disciplina e média geral.

## Tecnologia

- Python 3 (programa de terminal; não utiliza dependências externas conhecidas).

## Como executar

Tenha o Python 3 instalado. Na pasta do projeto, execute:

```bash
python Projeto
```

Em alguns ambientes, o comando pode ser `python3 Projeto`. Siga as perguntas exibidas no terminal para preencher os dados.

## Observações e limitações

- O arquivo-fonte se chama `Projeto` e não possui extensão `.py`; ele contém código Python.
- O programa espera pelo menos uma disciplina para gerar a média geral e converte a quantidade de disciplinas diretamente para inteiro. Informe uma quantidade inteira maior que zero.
- O programa é um exercício didático e não substitui um sistema acadêmico real.
